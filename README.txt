# آرشیو کوثر ۵

کتابخانه صوتی خصوصی با ۷ درس:

- اصول فقه ۲ — استاد بهشتی نژاد
- فقه ۱ — استاد رنجبر
- فلسفه اسلامی ۱ — استاد نجمی نژاد
- خانواده در اسلام — استاد عرب زاده
- مفاهیم — نامشخص
- بلاغت — استاد رحیمی
- تجزیه و ترکیب ۲ — استاد کریمی

ساختار سایت برای حدود ۱۰۰ جلسه در هر درس آماده است.

## نکته مهم درباره فایل‌های صوتی
با حدود ۷۰۰ فایل ۴۰ دقیقه‌ای، حجم آرشیو می‌تواند بسیار زیاد شود. GitHub Pages برای نگهداری مستقیم چنین آرشیوی مناسب نیست، و مخزن عمومی نیز برای صوت‌های امانتی مناسب نیست. بهتر است فایل‌های صوتی در یک فضای ذخیره‌سازی مناسب قرار بگیرند و سایت فقط آنها را پخش/لینک کند.

## کد ورود
فایل `config.js` را باز کن و مقدار `ACCESS_CODE` را تغییر بده.

هشدار: این کد ورود به‌تنهایی حفاظت واقعی از فایل‌های خصوصی ایجاد نمی‌کند، چون GitHub Pages یک سایت استاتیک است.


## نسخه جلسات
برای هر یک از ۷ درس، ۱۰۰ جلسه از قبل در سایت ساخته شده است. فعلاً هر جلسه
جای خالی برای فایل صوتی دارد و مدت آن حدود ۴۰ دقیقه نمایش داده می‌شود.
وقتی فایل‌ها آماده شدند، فقط مسیر فایل هر جلسه را به `audio` اضافه می‌کنیم.


## نسخه حرفه‌ای
این نسخه شامل لوگوی اختصاصی، ظاهر کتابخانه‌ای حرفه‌ای، صفحه‌بندی شیک،
و قابلیت ادامه پخش از آخرین زمان ذخیره‌شده برای هر جلسه است.
زمان پخش هر جلسه در مرورگر همان دستگاه ذخیره می‌شود. پس از اضافه کردن
فایل‌های واقعی، این قابلیت به‌صورت خودکار فعال خواهد شد.
